# Datos del proyecto

- **Dataset:** Spotify Tracks Dataset, autor maharshipandya (Kaggle).
- **Enlace:** https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset
- **Licencia:** Database: Open Database (ODbL); Contents: © Original Authors.
- **Archivo original:** dataset.csv, 114.000 canciones y 21 columnas.
- **Uso en este proyecto:** muestra aleatoria de 10.000 canciones (random_state=42). Tras la limpieza quedan 9.999.

El archivo original no se incluye en el repositorio. Para reproducir el análisis, descargar dataset.csv desde el enlace de Kaggle y cargarlo en el notebook de la carpeta notebooks.
